# 雀卓精算(Mahjong Scoreboard)

4人麻雀(半荘・25000点持ち)の点数をスマホで管理し、Google スプレッドシートに記録・集計する Google Apps Script(GAS)製ウェブアプリです。順位・ポイント計算は Mリーグ準拠です。

## 主な機能

- **点数管理**:4人の持ち点、局(東1局〜)、本場、供託棒を表示・調整
- **上がり入力**:ロン(ダブロン対応)/ツモ/流局(聴牌・ノーテン精算)を選び、飜数を指定して反映
  - 符計算は行わず、飜数から点数を算出(満貫・跳満・倍満・三倍満・役満は飜数で判定)
  - 本場・供託棒(リーチ棒)の精算、親の連荘/親流れを自動処理
- **立直管理**:各プレイヤーの「立直」ボタンで供託棒を管理
- **終局判定**:誰かの持ち点がマイナスになると終局を表示
- **履歴・取り消し**:操作履歴の表示と「ひとつ戻す」
- **1局ごとの自動保存**:確定ごとに月別の「対局記録」シートへ1行追記(未保存分の再送・強制再保存も可能)
- **半荘結果の保存**:「🏁 対局を終了して結果を保存」で順位・ポイントを計算し、「半荘結果」「月度順位」シートに反映
- **月度順位の集計**:月ごとにプレイヤー別の合計pt・平均順位・トップ率などを集計
- **Excel出力**:「現在の状況」「対局記録」「操作履歴」の3シートを含む `.xlsx` をダウンロード
- **設定**:開始点数の変更、スコアのリセット

## ルール(Mリーグ準拠)

| 項目 | 内容 |
| --- | --- |
| 持ち点 / 返し | 25000点持ち / 30000点返し |
| オカ | +20(トップ取り) |
| ウマ | 10-30 |
| 順位点 | 1位 +50 / 2位 +10 / 3位 −10 / 4位 −30(オカ込み) |
| 同点 | 起家に近い人が上位 |
| 残った供託 | トップが取得 |

合計pt = 素点pt((最終持ち点 − 30000) ÷ 1000)+ 順位点

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `code_20261005.gs` | GAS サーバー側。画面表示、記録保存、順位計算、月度集計、旧形式からの移行 |
| `index_20261005.html` | 画面(HTML/CSS/JavaScript)。点数計算ロジックを含む |

## セットアップ

1. Google スプレッドシートを新規作成し、「拡張機能 → Apps Script」を開く
2. `code_20261005.gs` の内容を `.gs` ファイルに貼り付ける(`.gs` のファイル名は任意)
3. HTML ファイルを **`index`** という名前で追加し、`index_20261005.html` の内容を貼り付ける
   (`doGet()` が `index` を読み込むため、名前は必ず `index` にする)
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」でデプロイし、発行された URL(`.../exec`)をスマホ等で開く

## シート構成

| シート名 | 単位 | 内容 |
| --- | --- | --- |
| `月度順位` | 1枚 | 月ごとのランキングを古い月から下へ並べる |
| `YYYY年MM月 半荘結果` | 月ごと | 1対局 = 4行(日付・月度・対局ID・プレイヤー・席順・最終持ち点・順位・素点pt・順位点・合計pt) |
| `YYYY年MM月 対局記録` | 月ごと | 1局 = 1行(局・親・上がり方・飜数・リーチ・供託・各人の増減と累計など) |

- 各シートは対局IDごとに背景色を変え、対局の区切りに太線を引きます。
- **月度の切り替わりは毎月1日の朝8時**です。0:00〜7:59 の対局は前月扱いになります(対局の開始時刻で判定)。
- 月度順位はプレイヤー名で集計するため、毎回同じ名前を使ってください。同ポイントは同順位です。

## スプレッドシートのメニュー

スプレッドシートを開くと「麻雀集計」メニューが追加されます。

- **月度順位を更新**:半荘結果を手で修正したときなどに、月度順位を作り直す
- **シートの色分けを更新**:既存データの色分けと区切り線を付け直す

## 旧形式からの移行

以前の1枚形式の「対局記録」「半荘結果」シートがある場合、保存時に自動で月別シートへ振り分け、元のシートは「(旧)」付きの名前に変更します。旧バージョンの「YYYY年MM月 順位」シートは削除されます。

## 備考

- Excel出力には CDN 経由の [SheetJS](https://sheetjs.com/)(xlsx 0.18.5)を使用しています。
- HTML を GAS 外で直接開いた場合、スプレッドシート保存は動作しません(点数計算と Excel 出力は利用可能)。
